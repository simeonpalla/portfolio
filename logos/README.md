# Organisation logos

Put each organisation's official logo file in this folder, then list it in `logos.json`.
A role with no logo listed keeps its monogram.

| Key | Organisation |
|---|---|
| `cpr` | Centre for Policy Research |
| `gitam` | GITAM University |
| `isb` | Bharti Institute of Public Policy, ISB |
| `myriad` | Myriad Concepts & Strategies |
| `goap` | Government of Andhra Pradesh |
| `pradical` | Pradical Works |
| `ballothouse` | The Ballot House |

Example `logos.json`:

```json
{ "cpr": "cpr.svg", "gitam": "gitam.png", "isb": "isb.svg" }
```

Use the organisation's official file (SVG preferred, or a PNG at least 256px wide with a transparent or white
background). Logos are shown on a white rounded tile so dark and coloured logos stay legible.
